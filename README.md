## My First App

1. **Judul Aplikasi (AppBar)**
   Bagian paling atas berwarna hijau bertuliskan **"My First App"**. Ini berfungsi sebagai papan nama atau identitas utama dari halaman.

2. **Area Gambar Utama**
   Kotak besar di tengah yang menampilkan sebuah foto. Ini adalah "soal" utama yang menjadi fokus perhatian untuk ditebak oleh pengguna.

3. **Papan Pesan (Feedback Box)**
   Kotak berwarna hijau muda bertuliskan *"What image is that?"*. Area ini bersifat dinamis, teksnya akan otomatis berubah memberikan respon (seperti ucapan "Benar" atau peringatan "Salah") ketika pengguna menekan tombol jawaban.

4. **Tombol Pilihan Jawaban**
   Kotak berwarna orange yang menyediakan 3 opsi tebakan: **Food** (Makanan), **Scenery** (Pemandangan), dan **People** (Orang). Ketiga ikon ini adalah tombol interaktif yang harus ditekan pengguna untuk menjawab.

5. **Area Penghitung Skor (Counter)**
   Kotak paling bawah berwarna ungu. Bagian ini berfungsi mencatat skor pengguna. Angkanya akan otomatis bertambah jika tebakan benar. Disediakan juga tombol ekstra **"+"** untuk mencoba menambah skor secara manual.
